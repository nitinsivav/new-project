# Framework-free Web Application
This project is a strict framework-free web application.

## Technology Stack
- **Frontend :** HTML, CSS, Vanilla JavaScript
- **Backend :** Java (Using Standard capabilities like `HttpServer`)
- **Database :** MySql
- **Database Communication :** JDBC
- **Build System :** Gradle

## Architecture Intent
The frontend is decoupled and strictly uses native browser technologies.
The backend handles server-side logic purely via Java without relying on frameworks like Spring or Express.
